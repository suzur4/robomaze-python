# ロボ迷路 Python

情報Ⅰ「アルゴリズムとプログラミング」第1時（アルゴリズムとその表記）の模擬授業用教材。
ブラウザだけで Python が動き、ロボットを動かしながら順次・反復・選択の3つの構造を学ぶ。

## ステップ

情報Ⅰ「アルゴリズムとプログラミング」全6時間分。画面上の「第1時〜第6時」で切りかえる。
ページは `#step-3`（第1時のステップ3）や `#step-5-2`（第5時のステップ2）で直接開ける。

| 時間 | ステップ | 教科書（実教出版『最新情報Ⅰ』） |
|---|---|---|
| 第1時 アルゴリズム | 順番／くり返し／場合分け（ドア。if と else）／自分で解く／right() が故障／模様／フラクタル | pp.162〜166 |
| 第2時 変数 | 変数と計算／x = x + 1／エラーを直す | pp.166〜168 |
| 第3時 分岐と反復 | 約数の判定／九九の7の段／1から10までの和／fizzbuzz | pp.169〜171、章末問題 |
| 第4時 リストと関数 | リスト／関数（四捨五入、大きいほう）／関数で迷路 | pp.171〜173 |
| 第5時 探索 | 線形探索／二分探索 | pp.174〜175 |
| 第6時 整列 | バブルソート／計算量のくらべ | pp.176〜178 |

第2時からは、迷路の代わりに「変数の箱」の欄で、変数の中身が1行ずつ変わる様子を見せる。
実行のあとは「1行もどる」「1行すすむ」で好きな行に戻れる。

迷路とロボットの絵は自作で、教科書の図は使っていない。

画面の青・黄・赤は、順次・反復・選択の3つの構造を表す（下の「色のきまり」）。

## 手元で動かす

`index.html` をダブルクリックしても動かない（ブラウザが Python 本体を読み込めない）。
このフォルダで簡単なサーバを立てて開く。

```
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開く。

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリの直下（または `docs/`）に置いて push する
2. リポジトリの Settings → Pages で、公開するブランチとフォルダを選ぶ
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

`.nojekyll` を同梱している（GitHub Pages がファイルを加工しないようにするため）。

## ファイル

- `index.html` / `style.css` / `app.js` … 画面
- `tokens.css` / `base.css` … 色・書体・余白の決まりと、全ページ共通の基本スタイル
- `robot.py` … Python 側。生徒のプログラムを実行して、ロボットの動きを記録する
- `pyodide/` … ブラウザで動く Python 本体（Pyodide 314.0.8、約13MB）。
  このフォルダを消すと、同じ版を CDN（jsDelivr）から読み込む

## 中身を変える

- ステップの文・迷路・最初のプログラム：`app.js` の先頭の `STAGES`
  - 迷路は文字で書く。`#` 壁、`.` 通路、`S` スタート、`G` ゴール
  - `door: true` でゴールにドアが付く。`disabled: ["right"]` で命令を故障させる
- ロボットの命令とエラーの文：`robot.py`

## 生徒が使える命令

迷路: `forward()` `left()` `right()` `open_door()` `door_is_open()`

模様: `forward(100)` `back(50)` `left(90)` `right(90)` `color("red")` `width(3)`
`pen_up()` `pen_down()` `goto(x, y)` `dot()` `dot(x, y)`

## 色のきまり

色は「順次・反復・選択のどれか」を表すときだけ使う。青＝順次、黄＝反復、赤＝選択。
フローチャートの箱、命令を入れるボタン、説明欄の札（例：「反復」）で同じ色になっている。
目次やステップの番号には色を付けない。

## 画面の色

ヘッダーの「画面の色」で4つから選べる（その端末に保存される）。どれでも上の色のきまりは同じ。

- パテ（標準）
- 白：明るい白地
- 黒：暗い画面。お絵かきの紙だけは白いまま
- くっきり：白地に黒い文字、線を太く。プロジェクターに映すときや、見えにくいとき

URL の最後に `?theme=white`（`dark`、`contrast`）を付けて開いても選べる。授業モードと一緒に使うなら `?teach&theme=contrast`。

## 授業で使うとき

- 授業モード：URL の最後に `?teach` を付けて開く（目次の下のボタンでも切りかえられる）。
  画面いっぱいに大きく表示し、ヒントを全部見せ、ドアの開き方（開いている・閉まっている）を選んで実行できる
- 1行ずつ実行：迷路のステップで「速さ」を「1つずつ」にすると、ボタンを押すたびに1つ進む
- まとめ：各時間の最後と目次から開ける。ふりかえりを書いてコピーできる
- 記録の消去：共用のパソコンでは、目次の下の「この端末の記録をすべて消す」か、URL に `?reset=1` を付けて開く

## 保存されるもの

進み具合と書いたプログラム、★、ふりかえりは、その端末のブラウザ（localStorage）にだけ保存される。
外部には何も送らない。
